# 租房合同智能生成与检查系统

## 项目概述

本项目是一个基于 Django 开发的租房合同智能生成与检查系统，利用 RAG (Retrieval-Augmented Generation) 技术实现合同条款的智能生成，并提供合同合规性检查功能。系统旨在帮助用户快速生成符合法律法规的租房合同，同时确保合同条款的合法性和有效性。

## 核心功能

### 1. 租房合同生成
- 基于用户需求，使用 RAG 技术智能生成租房合同条款
- 支持多次迭代优化，确保生成的合同符合法律法规
- 提供合同预览功能

### 2. 合同合规性检查
- 对生成的合同条款进行合规性审查
- 识别潜在的法律风险和问题
- 提供详细的问题反馈和修改建议

### 3. 用户管理
- 用户注册、登录、登出功能
- 用户个人信息管理
- 使用统计数据记录

### 4. 合同历史记录管理
- 查看历史合同列表
- 合同详情查看
- 合同导出功能
- 合同删除功能
- 合同状态管理

### 5. 法律条款爬取与知识库更新
- 定时自动爬取相关法律法规和标准合同条款
- 为 RAG 系统提供知识库更新
- 为合同合规性检查提供规则库更新

## 技术架构

### 后端技术
- **框架**: Django 5.1.7 + Django REST Framework
- **数据库**: MySQL
- **AI 技术**: LangChain + OpenAI API (阿里云 DashScope)
- **爬虫**: Scrapy
- **API 文档**: drf-spectacular (Swagger)

### 前端技术
- **模板引擎**: Django Templates
- **静态资源**: HTML, CSS, JavaScript

### 系统架构
1. **用户层**: 提供 Web 界面和 API 接口
2. **业务逻辑层**: 处理合同生成、检查等核心业务逻辑
3. **数据层**: 存储用户数据、合同数据等
4. **AI 层**: 实现 RAG 技术，提供智能生成和检查功能
5. **爬虫层**: 定期爬取法律条款，更新知识库

## 核心模块详解

### RAG 服务

RAG (Retrieval-Augmented Generation) 服务是本项目的核心，负责智能生成租房合同条款。

**主要功能**:
- 文档加载与预处理
- 向量索引构建与检索
- 基于检索结果的合同生成
- 语义缓存优化

**实现细节**:
- 使用 LangChain 实现 RAG 功能
- 支持 OpenAI 嵌入模型和大语言模型
- 实现了精确缓存和语义缓存，提高响应速度
- 支持文档分块和中文分词优化

### 合同检查服务

合同检查服务负责对生成的合同条款进行合规性审查，识别潜在的法律风险。

**主要功能**:
- 条款合规性检查
- 风险识别与评估
- 问题反馈与建议

### 用户管理系统

用户管理系统负责用户的注册、登录、个人信息管理等功能。

**主要功能**:
- 用户注册与登录
- 个人信息管理
- 使用统计数据记录

### 合同历史记录管理

合同历史记录管理系统负责用户合同的存储、查询、导出和删除等功能。

**主要功能**:
- 合同列表展示: 显示用户的所有历史合同，包括合同标题、状态、创建时间等信息
- 合同详情查看: 查看合同的详细内容
- 合同导出: 将合同导出为可打印的 HTML 格式
- 合同删除: 删除不需要的合同记录
- 合同状态管理: 跟踪合同的状态（草稿、已生成、已检查等）

### 法律条款爬虫与知识库更新

法律条款爬虫负责定时爬取相关法律法规和标准合同条款，为 RAG 系统提供知识库更新，同时为合同合规性检查提供规则库更新。

**主要功能**:
- 定时自动爬取法律条款和标准合同模板
- 处理和存储爬取的数据，构建结构化知识库
- 为 RAG 系统提供知识库更新，确保生成的合同符合最新法律法规
- 为合同合规性检查提供规则库更新，确保检查标准的时效性

**实现细节**:
- 使用 Scrapy 框架实现爬虫功能
- 支持定期自动爬取，可配置爬取频率
- 爬取的数据经过处理后，更新到 RAG 系统的知识库
- 同时更新合同合规性检查的规则库，确保检查逻辑与最新法律法规保持一致

## API 接口

### 合同生成接口
- **POST /api/generate/**: 根据用户需求生成租房合同
- **参数**: `demand` (用户需求描述)
- **返回**: 生成的合同条款、迭代历史、合规性检查结果

### 合同检查接口
- **POST /api/check/**: 检查合同合规性
- **参数**: `contract` (合同内容)
- **返回**: 检查结果、风险评估、修改建议

### 用户认证接口
- **POST /api/user/register/**: 用户注册
- **POST /api/user/login/**: 用户登录
- **POST /api/user/logout/**: 用户登出
- **GET /api/user/profile/**: 获取用户信息
- **PUT /api/user/profile/**: 更新用户信息
- **POST /api/user/stats/**: 更新用户统计数据

### 合同管理接口
- **GET /api/contract/**: 获取合同列表
- **POST /api/contract/**: 创建新合同
- **GET /api/contract/{id}/**: 获取合同详情
- **PUT /api/contract/{id}/**: 更新合同信息
- **DELETE /api/contract/{id}/**: 删除合同

## 安装与部署

### 环境要求
- Python 3.10+
- MySQL 5.7+
- pip

### 安装步骤

1. **克隆项目**
   ```bash
   git clone <项目地址>
   cd GraduateProject
   ```

2. **创建虚拟环境**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # Linux/Mac
   venv\Scripts\activate  # Windows
   ```

3. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

4. **配置环境变量**
   ```bash
   cp mysite/.env.example mysite/.env
   # 编辑 .env 文件，设置数据库连接和 API 密钥
   ```

5. **数据库迁移**
   ```bash
   cd mysite
   python manage.py migrate
   ```

6. **启动开发服务器**
   ```bash
   python manage.py runserver
   ```

### 生产部署

1. **配置生产环境**
   - 修改 `settings.py` 中的 `DEBUG = False`
   - 配置 `ALLOWED_HOSTS`
   - 配置静态文件收集

2. **使用 Gunicorn 和 Nginx**
   ```bash
   # 安装 Gunicorn
   pip install gunicorn
   
   # 启动 Gunicorn
   gunicorn mysite.wsgi:application --bind 0.0.0.0:8000
   ```

3. **配置 Nginx 反向代理**
   ```nginx
   server {
       listen 80;
       server_name example.com;
       
       location / {
           proxy_pass http://localhost:8000;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
       }
       
       location /static/ {
           alias /path/to/staticfiles/;
       }
       
       location /media/ {
           alias /path/to/media/;
       }
   }
   ```

## 使用指南

### 1. 生成租房合同
1. 登录系统
2. 进入合同生成页面
3. 输入需求描述，例如："生成一份租期为一年，月租3000元的租房合同"
4. 点击生成按钮，系统会自动生成合同条款并进行合规性检查
5. 查看生成结果，如有需要可修改需求后重新生成

### 2. 检查合同合规性
1. 登录系统
2. 进入合同检查页面
3. 上传或粘贴合同内容
4. 点击检查按钮，系统会对合同进行合规性审查
5. 查看检查结果，根据建议修改合同

### 3. 管理合同历史记录
1. 登录系统
2. 进入历史记录页面
3. 查看所有历史合同列表
4. 点击"查看"按钮查看合同详情
5. 点击"导出"按钮导出合同为可打印格式
6. 点击"删除"按钮删除不需要的合同记录

### 4. 管理个人信息
1. 登录系统
2. 进入个人中心
3. 查看和更新个人信息
4. 查看使用统计数据
